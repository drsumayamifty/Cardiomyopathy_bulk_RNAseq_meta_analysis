# # Cardiomyopathy Bulk RNA-seq Meta-analysis

## Project Overview

This repository presents a reproducible **bulk RNA-seq meta-analysis of human cardiomyopathy** using two publicly available Gene Expression Omnibus datasets:

- **GSE71613**
- **GSE55296**

The combined analysis includes **44 human cardiac tissue samples**, consisting of:

| Group | Number of samples |
|---|---:|
| Healthy controls | 14 |
| Cardiomyopathy | 30 |
| Total | 44 |

The cardiomyopathy group includes samples from patients with:

- Dilated cardiomyopathy
- Ischemic cardiomyopathy
- Restrictive cardiomyopathy

Because the datasets contain different cardiomyopathy subtypes, the main comparison in this project is:

> **Cardiomyopathy versus healthy cardiac tissue**

## Project Aim

The aim of this project is to identify recurrent transcriptional changes across independent cardiomyopathy RNA-seq datasets and explore the biological pathways and molecular networks associated with cardiac dysfunction.

Each dataset was analyzed separately before the gene-level results were combined through meta-analysis. This approach preserves study-specific characteristics and reduces problems caused by directly merging count matrices generated by different studies and sequencing platforms.

## Analysis Workflow

The project includes the following steps:

1. Import GREIN-derived raw count matrices and sample metadata
2. Filter low-expression genes
3. Assign samples to cardiomyopathy and healthy groups
4. Perform surrogate variable analysis
5. Conduct differential expression analysis using DESeq2
6. Generate PCA plots for sample-level assessment
7. Annotate genes and retain protein-coding genes
8. Compare study-level DEGs using a Venn diagram
9. Perform random-effects meta-analysis using MetaVolcanoR
10. Generate a pooled meta-analysis volcano plot
11. Perform functional enrichment analysis
12. Conduct Gene Set Enrichment Analysis
13. Build a STRING-based protein interaction network
14. Identify highly connected hub genes
15. Export publication-style tables and figures

## Functional Analyses

The downstream functional analyses include:

- Gene Ontology Biological Process
- Gene Ontology Molecular Function
- Gene Ontology Cellular Component
- KEGG pathways
- Reactome pathways
- MSigDB Hallmark gene sets
- Over-representation analysis
- Gene Set Enrichment Analysis
- Protein interaction and hub-gene analysis
